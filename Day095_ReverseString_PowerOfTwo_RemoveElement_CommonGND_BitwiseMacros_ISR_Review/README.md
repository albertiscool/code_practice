## 💻 一、 今日白板程式題（系統廠高頻 3 題全數通過）

### 1. 反轉字串 (Reverse String - LeetCode #344) -> [`p1.c`](./p1.c)
- **難度標籤**：🟢 系統廠高頻手寫必考題 | **複雜度**：時間 $O(N)$，空間 $O(1)$
- **核心思維**：同向/相向雙指針（Two Pointers）原地對撞交換。
- **盲點檢討**：
  - 置換時注意暫存變數取值：`char temp = s[left]; s[left] = s[right]; s[right] = temp;`
  - 避免誤寫成 `s[right] = s[temp]` 造成陣列越界存取（Out-of-bounds Read）導致字串在中間被 `'\0'` 截斷。

### 2. 2 的冪次方 (Power of Two - LeetCode #231) -> [`p2.c`](./p2.c)
- **難度標籤**：🟢 系統廠/硬體韌體位元運算必考題 | **複雜度**：時間 $O(1)$，空間 $O(1)$
- **核心思維**：位元運算神技 `n & (n - 1)` 消除最低位的 1。
- **經典考點與陷阱**：
  1. **運算子優先級**：關係運算子 `==` 優先於位元運算子 `&`，必須加上括號 `((n & (n - 1)) == 0)`。
  2. **邊界條件保護**：$n \le 0$（包含 0 與 `INT_MIN` 溢位），必須加入先決條件 `(n > 0)` 進行短路保護。
  3. **滿分解法**：`return (n > 0) && ((n & (n - 1)) == 0);`

### 3. 移除元素 (Remove Element - LeetCode #27) -> [`p3.c`](./p3.c)
- **難度標籤**：🟢 陣列原地操作高頻題 | **複雜度**：時間 $O(N)$，空間 $O(1)$
- **核心思維**：快慢雙指針（Fast-Slow Pointers）。
- **實作亮點**：
  - `fast` 負責遍歷全陣列，`slow` 負責就定位覆寫合法數值，邏輯清晰且零額外記憶體開銷。
  - 完美通過空陣列（`numsSize = 0`）與全部元素皆為 `val` 等極限邊界測資。

## 🚗 二、 自走車專案實務科普（系統廠面試官最愛問的三大魔王題）

### 1. 電源架構與雜訊隔離（共地 Common Ground、BOD 欠壓復位與大小電容）
- **馬達啟動造成 MCU 重開機之物理原因**：直流馬達啟動瞬間存在巨大突波電流（Inrush Current），瞬間拉低電源電壓（Voltage Sag），觸發 MCU 內部的 Brown-out Detector (BOD) 硬體復位。
- **電源分離＋共地**：強電（馬達 12V）與弱電（MCU/樹莓派 5V）電源各自獨立，但**地線（GND）必須相連共地**，提供 UART 與 PWM 邏輯訊號一致的 0V 參考電位。
- **大小電容選型職責**：
  - **大電容（470$\mu$F 電解 Bulk Capacitor）**：充當微型水庫，瞬間放電補償突波電流，防止電壓跌落。
  - **小電容（0.1$\mu$F MLCC 去耦 Decoupling Capacitor）**：高頻低阻抗，專門將馬達碳刷換向產生的數百 kHz 尖峰雜訊導引至地線。

### 2. 跨板通訊與安全機制（500ms 心跳 Failsafe 機制）
- **上位機與下位機防暴衝**：樹莓派（Linux ROS 2）與 Arduino 透過自訂二進位封包（幀頭、長度、有效載荷、Checksum）傳輸。
- **軟體看門狗**：Arduino 端記錄最後一次通訊時間戳記，一旦超過 500ms 未收到新封包或心跳，自動強制煞停並發出聲光警報，防止上位機當機導致車輛失控。

### 3. 電機驅動模式差異（L298N 慣性滑行 Coasting vs 動態煞車 Dynamic Braking）
- **慣性滑行 (Coasting)**：`PWM = 0`，馬達兩端開路，僅靠機械摩擦力減速，煞車距離長。
- **動態煞車 (Dynamic Braking)**：將 H 橋上下臂短路，利用馬達運轉產生的**反電動勢 (Back-EMF)** 在線圈內部產生反向感應電流與電磁阻尼力矩，達成瞬間急煞。

## 🎙️ 三、 0x10 嵌入式 C 語言底層核心考題

### 題 1：位元操作 4 大巨集 (Bitwise Macros) -> [`0x10_1.c`](./0x10_1.c)
```c
#define SET_BIT(reg, n)    ((reg) |= (1U << (n)))
#define CLEAR_BIT(reg, n)  ((reg) &= ~(1U << (n)))
#define TOGGLE_BIT(reg, n) ((reg) ^= (1U << (n)))
#define CHECK_BIT(reg, n)  (((reg) >> (n)) & (1U))
```
- **資深工程師亮點**：使用 `1U` 避免常數 `1`（有號整數）位移至第 31 位元時觸發符號位溢位（Signed Overflow / UB）；所有巨集參數與本體均使用括號做完整防禦性保護。

### 題 2：中斷服務常式 (ISR) 三大禁忌
1. **禁呼叫 `printf()` 與 `malloc()` / `free()`**：
   - `malloc()` 涉及動態記憶體配置並依賴全域 Heap 鎖；若 `main()` 正在執行 `malloc()` 期間發生中斷，ISR 再次呼叫 `malloc()` 嘗試搶鎖，將引發**自我死鎖（Self-Deadlock）**。
   - `printf()` 具備 I/O 阻塞性且耗時達毫秒級，破壞中斷極速退出原則。
2. **禁使用 `delay()` 或長時間迴圈**：
   - ISR 執行時通常關閉或遮蔽其他中斷，長時間延遲將導致全系統中斷飢餓（Interrupt Starvation）、UART 等通訊緩衝區溢位與嚴重掉包。
   - 許多 `delay()` 函式依賴 SysTick 中斷累加計時，在關閉中斷的環境下呼叫會導致永久卡死。
3. **主迴圈與 ISR 共享變數宣告**：
   - 必須加上 **`volatile`**（如 `volatile bool flag;`），禁止編譯器將變數快取於 CPU 暫存器中，強制每次存取皆從實體 SRAM 記憶體讀取最新數值。
