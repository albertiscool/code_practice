# Day 100 里程碑：一線 IC 白板演算法全數通關（相交串列、回文串列、雙指針兩數之和）

今天正式邁入極具紀念價值的 **Day 100**！全面攻克一線 IC 設計廠（聯詠、瑞昱、聯發科、群聯）高頻出現的動態指標與雙指針邊界夾擊題，三題均以嚴格的 $O(1)$ 空間複雜度與滿分規範通過驗證！

## 💻 今日白板程式題全紀錄

### 1. 相交鏈結串列 (Intersection of Two Linked Lists - LeetCode #160) -> [`p1.c`](./p1.c)
- **難度標籤**：🟡 一線 IC 設計廠 雙指標經典高頻題 | **複雜度**：時間 $O(M + N)$，空間嚴格 $O(1)$
- **實作亮點（100 分滿分一次過）**：
  - 展現極致的數學對稱美：**$A + B = B + A$ 雙指針路徑等長化**。
  - 指針 A 走完 A 轉往 B，指針 B 走完 B 轉往 A。雙方走過總距離皆為 $a + b + c$，必在相交點同時相遇。
  - 自然吸收不相交邊界：若無交點，兩指針走完各自路徑後會「同時抵達 NULL」，條件 `currA == currB` 自然成立退出，完全不需額外計數器。

### 2. 回文鏈結串列 (Palindrome Linked List - LeetCode #234) -> [`p2.c`](./p2.c)
- **難度標籤**：🟡 一線 IC 設計廠與系統廠 動態指標綜合考查題 | **複雜度**：時間 $O(N)$，空間嚴格 $O(1)$
- **三大指標技能無縫串接**：
  1. 快慢指針（`slow`, `fast`）找到鏈結串列中點。
  2. 原地滑動反轉後半段串列（`pre`, `slow`, `next_node`）。
  3. 前後雙指針向內同步逐值比對。
- **指針筆誤盲點檢討（已存檔使用者原始程式碼）**：
  - 在反轉迴圈結束後，`p1` 已經一路走到鏈結串列末端的 `NULL`，反轉後的頭節點保存在 `pre` 當中。
  - 原寫法在比對時誤寫為 `while (p1 != NULL)`，導致比對迴圈未被執行即直接跳出回傳 `true`。
  - **修正**：將比對條件修訂為 `while (p2 != NULL)`（其中 `p2 = pre`），完整通過 4 組奇偶與非回文邊界測試。

### 3. 兩數之和 II - 輸入有序陣列 (Two Sum II - LeetCode #167) -> [`p3.c`](./p3.c)
- **難度標籤**：🟡 聯發科、聯詠、群聯 雙指針邊界夾擊必考題 | **複雜度**：時間 $O(N)$，空間嚴格 $O(1)$
- **實作亮點（100 分滿分一次過）**：
  - 利用陣列「升序排序」之單調性，採用首尾雙指針向內夾擊：
    - 兩數之和太小（`< target`） $\implies$ `left++` 放大總和。
    - 兩數之和太大（`> target`） $\implies$ `right--` 縮小總和。
  - 嚴格達成題目要求的 1-based index 轉換與記憶體配置，一次性通過所有正負數測試。
