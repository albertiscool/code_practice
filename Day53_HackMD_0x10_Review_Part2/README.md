## 📝 實戰考題與詳細解答 (HackMD 0x10 Questions 4~6)

### HackMD 第 4 題【嵌入式系統的無窮迴圈 Infinite Loops】
* **原問題**：寫出 3 種 C 語言無窮迴圈。`while(1)` vs `for(;;)` 差異與低功耗指令？
* **解析與解答**：
  1. **3 種無窮迴圈寫法**：`while(1) {}`、`for(;;) {}`、`Loop: ... goto Loop;`。
  2. **`for(;;)` 偏好原因**：傳統編譯器中 `while(1)` 會評估 `1 != 0` 常數條件，`for(;;)` 少了條件判斷，編譯為無條件跳轉指令 (`JMP`/`B`)。靜態檢查工具 (Lint) 亦偏好 `for(;;)` 以防常數條件警告。
  3. **低功耗 `WFI`**：在 MCU 主迴圈放入 `__WFI()` (Wait For Interrupt) 指令，可暫停 CPU 時脈進入低功耗休眠，直至中斷喚醒。

### HackMD 第 5 題【C 語言複雜宣告與指標大對決 (a ~ h)】
* **原問題**：寫出 a ~ h 8 種複雜宣告。
* **解析與解答**：
  * **a)** `int a;` (整數)
  * **b)** `int *a;` (指向整數的指標)
  * **c)** `int **a;` (指向指標的指標)
  * **d)** `int a[10];` (包含 10 個整數的陣列)
  * **e)** `int *a[10];` (指標陣列：本質是陣列，裝 10 個 `int*` 指標)
  * **f)** `int (*a)[10];` (陣列指標：本質是指標，用小括號強制優先結合，指向 `int[10]` 陣列)
  * **g)** `int (*a)(int);` (函式指標：指向接收 1 個 int 參數並回傳 int 的函式)
  * **h)** `int (*a[10])(int);` (函式指標陣列：包含 10 個指標的陣列，每個指標指向接收 int 回傳 int 的函式)

### HackMD 第 6 題【關鍵字 static 的 3 大作用】
* **原問題**：`static` 的 3 種不同作用？
* **解析與解答**：
  1. **隱藏作用 (Limit Linkage/Scope)**：在 `.c` 檔案全域宣告 `static` 變數或函式，作用域限制於該編譯單元內部。其餘 `.c` 檔使用 `extern` 亦無法存取，防範命名衝突。
  2. **延長生命週期 (Persistent Lifetime)**：在函式內宣告 `static` 變數，其儲存於 `.data` 或 `.bss` 靜態段。函式 return 後記憶體不銷毀，跨呼叫保有上次執行結果。
  3. **預設初始化為 0**：未給初值的 static 變數，編譯器預設初始化為 `0x00`。
