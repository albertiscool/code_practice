## 💻 白板程式題實作與檢討

### 題目 1：合併兩個有序陣列 (Merge Sorted Array - LeetCode #88)
- **檔案**：[`p1.c`](./p1.c)
- **難度**：🟢 Easy | **出題頻率**：🔥🔥🔥🔥🔥
- **核心算法**：從後往前雙指標 / 三指標技巧，時間複雜度 $O(M + N)$，額外空間複雜度 $O(1)$。
- **重要邊界與語法陷阱**：
  - **變數 Scope 陷阱**：避免在 `if-else` 區塊內部宣告指針變數，否則離開大括號後該變數會消亡導致編譯錯誤。
  - **負數索引越界防護**：
    `if (p1 >= 0 && nums1[p1] > nums2[p2])`
    當 `nums1` 的有效元素提前消耗完畢（`p1 = -1`），必須透過 `p1 >= 0` 結合 C 語言**短路求值（Short-Circuit Evaluation）**機制，避免存取 `nums1[-1]` 造成越界錯誤，安全進入 `else` 搬移 `nums2` 剩餘元素。

### 題目 2：除自身以外陣列的乘積 (Product of Array Except Self - LeetCode #238)
- **檔案**：[`p2.c`](./p2.c)
- **難度**：🟡 Medium | **出題頻率**：🔥🔥🔥🔥🔥
- **核心算法**：雙向遍歷（Prefix & Suffix Product），時間複雜度 $O(N)$，嚴禁使用除法，額外空間 $O(1)$。
- **演算法結構**：
  1. **第一趟（左往右）**：`left = 1`，`ans[i] = left`，隨後 `left *= nums[i]` 記錄當前位置左邊所有人的乘積。
  2. **第二趟（右往左）**：`right = 1`（乘法單位元素），`ans[j] *= right`，隨後 `right *= nums[j]` 累積右側所有人的乘積。
- **原始盲點檢討**：
  - 乘法累乘變數初始值必須為 `1`，若誤設為 `0` 會使整個陣列元素全數歸零。
  - 累積乘積必須乘上原始陣列 `nums[i]`，而非剛剛賦值的 `ans[i]`。
  - 反向遍歷迴圈必須使用 `j--`，誤寫為 `j++` 會引發無窮迴圈。

### 題 1：自走車專案實務 - 雙核心通訊斷線防護、Heartbeat 機制與動態煞車

#### 1. 通訊逾時看門狗（Communication Timeout Watchdog）
- **心跳檢測**：上位機（ROS 2 / Linux）以固定頻率（如 10Hz / 100ms）發布 `/cmd_vel`。下位機（Arduino）於每次成功校驗並解碼指令時刷新時間戳 `last_cmd_time = millis()`。
- **逾時判斷與狀態保護**：主迴圈週期性檢查 `if (millis() - last_cmd_time > 300ms)`。一旦逾時立即進入 `STATE_FAILSAFE` 狀態，並強制鎖定，直到重新連線握手且接收到速度歸零指令才解除，防止通訊跳動造成自走車暴衝。

#### 2. L298N 緊急動態煞車（Dynamic Braking）
- **腳位配置**：`ENA = HIGH (PWM 255)`，`IN1 = HIGH, IN2 = HIGH`（或兩者皆 LOW）。
- **物理底層原理**：
  - H 橋開關將馬達線圈兩端短路到同一電位。
  - 馬達旋轉時化身為發電機產生反電動勢（Back-EMF: $V = K_e \cdot \omega$）。
  - 因線圈端點短路，產生極大逆向感應電流（$I = V / R_{\text{coil}}$）。
  - 根據**冷次定律（Lenz's Law）**，產生強大的逆向電磁阻尼力矩（$\tau = K_t \cdot I$），在數十毫秒內將馬達強制鎖死。
- **為什麼不用 `ENA = 0`（Coast 滑行）？**
  - `ENA = 0` 會使 H 橋呈現高阻抗（High-Z）開路，無感應電流迴路，小車僅能靠微弱機械摩擦力滑行，煞車距離過長，必然撞毀。

### 題 2：0x10 C 語言底層核心 - 系統記憶體五大區段與 Startup 初始化

#### 1. 五大區段與生長方向
- **Text 區段**：存放 CPU 機器碼指令與唯讀資料（`.rodata`），在 MCU 中通常常駐於 Flash ROM 執行（XIP）。
- **Data 區段**：存放**已初始化且初值非 0** 的全域與靜態變數（可讀寫，位於 SRAM）。
- **BSS 區段**：存放**未初始化或初值為 0** 的全域與靜態變數（位於 SRAM）。
- **Heap 區段**：`malloc` 動態分配區，由低位址向高位址生長（**向上長**）。
- **Stack 區段**：存放函式區域變數、參數、返回位址與暫存器框架，由高位址向低位址生長（**向下長**）。

#### 2. CRT0 / Reset Handler 開機初始化行為
- **`.data` 區段（Flash $\to$ SRAM 複製）**：初值保存在 Flash（LMA），啟動代碼將其拷貝至 SRAM 執行位址（VMA）。
- **`.bss` 區段（SRAM 清零 Zero-fill）**：二進位檔僅記錄 BSS 起始位址與大小，開機代碼使用 `memset` 將整塊 SRAM 清為 0，確保未初始化變數預設值為 0。

#### 3. 變數配置陷阱分析
- `static int g_c = 0;` $\to$ **`.bss`**（初值為 0 會被編譯器優化放進 BSS，省下 Flash 空間）。
- `const int g_d = 20;` $\to$ **`.rodata` / Text**（唯讀常數放在 Flash ROM，不佔用 SRAM）。

### 題 3：🔥 0x10 經典進階指標解析與陣列步長運算

#### 1. 右左法則（Right-Left Rule）宣告解析
- ① `int *p[10];` $\to$ **指標陣列**（包含 10 個 `int*` 指標的陣列）。
- ② `int (*p)[10];` $\to$ **陣列指標**（指向一個包含 10 個 `int` 的陣列之指標）。
- ③ `int *(*p)[10];` $\to$ **指向指標陣列的指標**（指向一個包含 10 個 `int*` 指標陣列的指標）。
- ④ `int (*p(int))[10];` $\to$ **回傳陣列指標的函式**（`p` 是一個函式，接收 `int`，回傳指向大小為 10 之 `int` 陣列的指標）。
- ⑤ `int (*p[10])(int);` $\to$ **函式指標陣列**（包含 10 個函式指標的陣列，每個函式接收 `int` 並回傳 `int`）。

#### 2. 陣列步長陷阱運算
```c
int a[5] = {1, 2, 3, 4, 5};
int *ptr = (int *)(&a + 1);
printf("%d, %d\n", *(a + 1), *(ptr - 1));
```
- **輸出結果**：**`2, 5`**
- **底層記憶體原理**：
  1. `a` 為首元素指標（型別 `int*`），`a + 1` 移動 $4\text{ bytes}$ 指向 `a[1]`，`*(a + 1) = 2`。
  2. `&a` 為指向整個陣列的指標（型別 `int (*)[5]`），其步長為 $5 \times 4 = 20\text{ bytes}$。
  3. `&a + 1` 跨越整個陣列指向尾端邊界外（`a[5]` 的位址）。
  4. 強制轉型為 `int* ptr` 後，`ptr - 1` 的步長退回 $4\text{ bytes}$，指回 `a[4]`，`*(ptr - 1) = 5`。
