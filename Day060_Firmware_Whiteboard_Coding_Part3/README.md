## 🔬 C 語言底層剖析：運算子優先順序與賦值時機

### 1. `*` 與 `++` 優先順序層級
* **後置運算子 (Postfix: `p++`, `p--`)**：優先級第一級（最高），從左到右結合。
* **單元/前置運算子 (Unary/Prefix: `*p`, `++p`)**：優先級第二級，從右到左結合。

### 2. 賦值 `=` 什麼時候把值交給變數？
* **核心規則 1**：`val = <運算式>;` 永遠在**右邊算式算出最終數值後**才丟給左邊變數。
* **核心規則 2**：
  * **後置 `++`**：右邊算式交給 `=` 的一定是 **「發動前的舊值」**；等號賦值完成後才發動指標/內容遞增的副作用 (Side Effect)。
  * **前置 `++`**：算式會先進行遞增，交給 `=` 的一定是 **「更新後的新值」**。

### 3. 三大常見寫法實測比較 (`int a[2] = {10, 20}; int *p = a;`)
| 語法寫法 | 賦值給 `val` 的數值 | 指標 `p` 位址是否有變？ | 記憶體格子內容是否有變？ |
| :--- | :--- | :--- | :--- |
| **`val = *p++`** | **`10`** (舊值) | **有變** (移向 `a[1]`) | 沒變 (`a[0]=10, a[1]=20`) |
| **`val = (*p)++`** | **`10`** (舊值) | **沒變** (仍指向 `a[0]`) | **有變** (`a[0]` 變成 `11`) |
| **`val = *++p`** | **`20`** (新值) | **有變** (移向 `a[1]`) | 沒變 (`a[0]=10, a[1]=20`) |

### 題目 4【快慢指標偵測鏈結串列環 (Floyd's Cycle Detection) 與入口數學推導】
* **原始碼檔案**：[`p4.c`](file:///c:/Users/a0907/Desktop/%E7%A8%8B%E5%BC%8F%E8%A8%93%E7%B7%B4/Day60_Firmware_Whiteboard_Coding_Part3/p4.c)

#### 任務 1：判斷是否有環 (`hasCycle`)
* **核心演算法**：慢指標每次走 1 步 (`slow = slow->next`)，快指標每次走 2 步 (`fast = fast->next->next`)。若相遇 (`slow == fast`) 則代表有環！
* **標準防呆條件**：`while (fast != NULL && fast->next != NULL)`。

#### 任務 2：尋找環的入口節點 (`detectCycleEntry`) 與數學證明
```
Head (起點)                      Entry (環入口)
 * ------------ L 步 ------------> * 
                                  / \
                            b 步 /   \
                                v     \ 
                             相遇點    |  (環總長為 C = b + c)
                            (Meeting) |
                                \     /
                            c 步 \   /
                                  \ /
                                   *
```
* **數學推導**：
  1. $D_{slow} = L + b$
  2. $D_{fast} = L + b + k \cdot C$
  3. 因為 $D_{fast} = 2 \cdot D_{slow}$ ➡️ $L + b + k \cdot C = 2(L + b)$
  4. 移項化簡：$L = k \cdot C - b = (k - 1) \cdot C + (b + c) - b$ ➡️ **$L = (k - 1) \cdot C + c$**
  5. **結論：$L = c$！從起點 `Head` 到環入口的步數，剛好等於從「相遇點」走到環入口的步數！**
* **演算法實作**：快慢指標相遇後，一個指標從 `Head` 出發，另一個留在相遇點，兩者每次皆走 1 步，**再次相遇的節點 100% 就是環的入口！**

### 題目 5【句子中單字原地反轉 (Reverse Words in a Sentence)】
* **原始碼檔案**：[`p5.c`](file:///c:/Users/a0907/Desktop/%E7%A8%8B%E5%BC%8F%E8%A8%93%E7%B7%B4/Day60_Firmware_Whiteboard_Coding_Part3/p5.c)
* **題目要求**：將 `"the sky is blue"` 原地轉為 `"blue is sky the"`，空間複雜度必須為 **$O(1)$**（禁止配置額外記憶體）。

#### 兩階段翻轉法演算法流程：
1. **第一步（全字串翻轉）**：
   使用雙指標 `first` 與 `last` 對撞交換，將整條句子完全反轉：
   `"the sky is blue"` ➡️ **`"eulb si yks eht"`**
2. **第二步（個別單字翻轉回來）**：
   遍歷字串，以空格 `' '` 為界找出各單字區間，使用雙指標對撞將單字轉正：
   * `"eulb"` ➡️ `"blue"`
   * `"si"`   ➡️ `"is"`
   * `"yks"`  ➡️ `"sky"`
   * `"eht"`  ➡️ `"the"`
   * 最終結果：**`"blue is sky the"`**！

#### 核心盲點與 C 語言字串指標避坑總結：
1. **結尾檢查**：字串結尾是字元 `*ptr == '\0'`，而非指標 `ptr == NULL`。
2. **雙指標終止條件**：左右指標對調的條件永遠是 **`while (left < right)`**，不可使用 `left != NULL` 避免越界。
3. **未定義行為**：`last = last++;` 為未定義行為，應單純寫 `last++;`。
