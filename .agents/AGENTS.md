# 專案專屬行為規則 (Workspace Customizations)

- **自動重新命名資料夾**：當幫使用者整理每日的內容（例如 Day22, Day23...）並準備上傳 GitHub 時，必須「主動且自動」將當天的資料夾名稱加上當天的學習大綱名稱（例如從 `Day22` 改名為 `Day22_TopicName`），即使使用者沒有特別開口提醒也必須執行，並且連同改名後的結果一起 Commit 和 Push。
- **每日面試口試題目配置（Day 91+）**：
  - **題 1**：自走車專案實務（雙核心 ROS 2 / Linux + Arduino、感測器融合、馬達驅動、系統除錯與 Failsafe）
  - **題 2**：0x10 C 語言底層核心 / RTOS / 系統記憶體架構
  - **題 3**：**0x10 經典嵌入式 C 語言與韌體面試精選題複習**（全面輪替 HackMD 0x10 經典考點：進階指標與函式指標、結構體 Memory Padding / Alignment、位元運算與 Mask、MMIO 暫存器映射、變數生命週期與 Scope、Volatile / Const、巨集陷阱與防禦式程式設計等）
