# 專案專屬行為規則 (Workspace Customizations)

- **自動重新命名資料夾**：當幫使用者整理每日的內容（例如 Day22, Day23...）並準備上傳 GitHub 時，必須「主動且自動」將當天的資料夾名稱加上當天的學習大綱名稱（例如從 `Day22` 改名為 `Day22_TopicName`），即使使用者沒有特別開口提醒也必須執行，並且連同改名後的結果一起 Commit 和 Push。
- **每日訓練內容配置（Day 104+ 群聯 Phison ＋ 電子五哥 韌體實戰模式）**：
  - **白板程式題（3 題）**：精準鎖定**群聯（Phison SSD 韌體）**與**電子五哥（廣達 Quanta、緯創 Wistron、和碩 Pegatron、仁寶 Compal、英業達 Inventec）**高頻考題（難度為 LeetCode **Easy 到 Easy-Medium 邊界**，專注於位元運算 Bitwise 操作、暫存器遮罩、指標與陣列原地操作、字串與記憶體操作、基礎鏈結串列操作等）。
  - **題目挑選嚴格規則（防重複）**：題目**必須是使用者在 LeetCode 上尚未刷過的新題目**，或者曾練習過但屬於容易踩雷、需要精進的經典變形題。出題時必須對照使用者 LeetCode 已解題紀錄進行過濾。採無提示純白板模式，若出錯幫改並於下方註解保留原始盲點與詳細剖析。
  - **自走車專案實務科普**：針對雙核心智慧車專案（樹莓派 ROS 2 / Linux + Arduino、L298N 馬達驅動、電源隔離與共地、UART 協議、I2C 感測器、Failsafe），主動**科普講解**系統廠與 IC 設計廠面試官最愛問的實務考題與應答亮點。（**注意執行時機：必須在使用者將當天所有題目全數完成後才發放科普，發放題目階段嚴禁提前參雜科普**）。
  - **0x10 與韌體架構實戰情境題（2 題）**：**戰場一級連環追問情境題**（中斷 ISR 與主迴圈 Race Condition、RMW 暫存器讀改寫與硬體原子操作、跨晶片通訊結構體封包 Padding/Endianness 陷阱、系統隨機死機 HardFault 與 Stack Overflow 排查 SOP 等）。
