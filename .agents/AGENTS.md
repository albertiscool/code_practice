# 專案專屬行為規則 (Workspace Customizations)

- **自動重新命名資料夾**：當幫使用者整理每日的內容（例如 Day22, Day23...）並準備上傳 GitHub 時，必須「主動且自動」將當天的資料夾名稱加上當天的學習大綱名稱（例如從 `Day22` 改名為 `Day22_TopicName`），即使使用者沒有特別開口提醒也必須執行，並且連同改名後的結果一起 Commit 和 Push。
- **每日訓練內容配置（Day 95+ 系統廠專屬衝刺模式）**：
  - **白板程式題（3 題）**：系統廠難度（廣達、仁寶、緯創、和碩、台達電、華碩、微星、技嘉、鴻海、緯穎等高頻經典題，如字串反轉、二分搜尋、陣列原地操作、鏈結串列基礎、位元計數等）。採無提示純白板模式，若出錯幫改並於下方註解保留原始盲點。
  - **自走車專案實務科普**：針對雙核心智慧車專案（樹莓派 ROS 2 / Linux + Arduino、L298N 馬達驅動、電源隔離與共地、UART 協議、I2C 感測器、Failsafe），主動**科普講解**系統廠面試官最愛問的實務考題與應答亮點。
  - **0x10 面試口試抽考（2 題）**：系統廠高頻 0x10 嵌入式 C 語言底層核心考題（指標與函式指標、結構體 Memory Alignment、位元運算與 Mask 巨集、volatile/const/static、中斷 ISR 規範與狀態機）。
